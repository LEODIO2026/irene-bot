# 아이린 모의거래 터미널

신규 토큰을 실시간으로 살펴보면서 **가상 잔고로만** 거래해 보는 연습용 터미널입니다.
실제 주문은 어디에도 나가지 않고, 지갑·개인키·거래소 API 키를 전혀 쓰지 않습니다.
기존 아이린 실거래 봇(`main.py`)과는 완전히 분리되어 있습니다.

## 실행

```bash
pip install flask requests

python -m paper_terminal                 # 실제 시장 데이터 (DexScreener + RugCheck, 키 불필요)
python -m paper_terminal --source sim    # 지어낸 가상 시장 (화면 구경용, 인터넷 불필요)
```

브라우저에서 <http://127.0.0.1:9191> 을 엽니다.

**맥에서는** 저장소 폴더의 `start_paper_terminal.command` 파일을 더블클릭하면
준비부터 실행, 브라우저 열기까지 한 번에 됩니다. (처음에 "확인되지 않은 개발자" 경고가 뜨면
파일을 오른쪽 클릭 → 열기)
NAS에서 띄우려면: `docker-compose -f docker-compose.paper.yml up -d`

## 여섯 에이전트

| # | 이름 | 하는 일 |
|---|------|---------|
| 1 | 스캐너 | 새로 등록된 토큰 중 5분 거래량이 급증하고 매수가 우세한 것을 찾음 |
| 2 | 러그 체크 | 유동성 부족, 허니팟 의심, LP 미잠금, RugCheck 위험 항목이 있으면 차단 |
| 3 | 사이저 | 고정 금액이 아니라 현재 자산에 비례해 크기 결정 (손절 시 자산의 2%만 손실) |
| 4 | 실행기 | 가상 매수·매도. 가격 충격, DEX 수수료, 네트워크 수수료를 반영하고 슬리피지를 기록 |
| 5 | 로거 | 모든 판단(진입·차단·건너뜀·청산)의 이유를 기록 |
| 6 | 수익 곡선 | 거래가 끝날 때마다 자산 곡선 갱신 |

청산 규칙: 손절 -15%, 익절 +35%, 추적 손절(+15% 이후 고점 대비 -10%), 90분 시간 청산,
유동성 급감 시 긴급 청산, 시세가 5회 연속 사라지면 전액 손실 처리.

## 설정

모든 값은 환경변수로 바꿀 수 있습니다 (`config.py` 참고). 자주 쓰는 것:

| 변수 | 기본값 | 뜻 |
|------|--------|----|
| `PAPER_START_BALANCE` | 44.82 | 가상 시작 잔고(USD) |
| `PAPER_POLL_SECONDS` | 30 | 확인 주기 |
| `PAPER_MIN_LIQUIDITY` | 15000 | 최소 풀 유동성(USD) |
| `PAPER_RISK_PER_TRADE` | 0.02 | 거래당 감수할 자산 비율 |
| `PAPER_STOP_LOSS` / `PAPER_TAKE_PROFIT` | 0.15 / 0.35 | 손절 / 익절 |
| `PAPER_HOST` / `PAPER_PORT` | 127.0.0.1 / 9191 | 대시보드 주소 |

## 알아둘 점

- 모의 체결은 실제보다 유리합니다. 30초마다 한 번 보는 가격으로 체결되고, MEV·샌드위치 공격,
  전송 실패, 매도세(tax) 토큰 같은 것은 반영되지 않습니다. 여기서 수익이 나도 실전에서는 손실일 수 있습니다.
- `--source sim`의 가상 시장은 화면을 보기 위한 것이라 손익에 아무 의미가 없습니다.
- 대시보드에는 로그인 기능이 없습니다. 외부 인터넷에 직접 노출하지 마세요.
